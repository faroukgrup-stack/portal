# المنصة الشاملة — FAROUK GRUP (النسخة المنظمة)

تمت إعادة هيكلة المشروع بحيث يصبح كل ملف في مكانه الصحيح، ويصبح التطوير أسهل بكثير.
المشروع يدعم الآن **ثلاث لغات**: العربية `ar` — English `en` — Türkçe `tr`.

---

### نظام التصميم الموحد (متغيرات CSS)

كل ملفات CSS تبدأ الآن ببلوك `:root` يعرّف هوية المنصة كاملة — **تعديل أي قيمة هنا ينعكس على المنصة كلها**:

```css
:root {
    /* الألوان */
    --gold: #cfa776;        /* الذهبي الأساسي */
    --gold-deep: #b48554;   /* الذهبي الغامق */
    --gold-bright: #d4b15a; /* الذهبي الفاتح */
    --bg: #0b0e17;  --bg-2: #121824;   /* الخلفيات الداكنة */
    --text: #f0f4fa;        /* النص الأساسي */
    --text-muted: #b8c5dc;  /* النص الثانوي (مفتّح لتحسين التباين) */
    --danger: #dc3545; --danger-soft: #f87171;
    --success: #28a745; --warning: #ffc107;
    /* الانحناءات — مقياس من 5 قيم فقط */
    --radius-xs: 4px; --radius-sm: 10px; --radius-md: 20px;
    --radius-lg: 30px; --radius-xl: 40px;
}
```

كانت الألوان مكتوبة يدويًا (الذهبي وحده 312 مرة) والانحناءات 14 قيمة مختلفة — الآن كلها متغيرات ومقياس موحد.

### نظام CSS الطبقي للأدوات (الأهم للتطوير السريع)

كل صفحة أداة تُحمّل ثلاث طبقات بالترتيب:

| الترتيب | الملف | وظيفته | متى تعدله؟ |
|---|---|---|
| 1 | `css/tools-common.css` | ⭐ التصميم الموحد كاملاً (564 قاعدة — أغلبية قوالب كل الأدوات) | لتعديل تصميم كل الأدوات دفعة واحدة |
| 2 | `css/tools/toolN.css` | المكونات الخاصة بأداة واحدة فقط (~4KB لكل أداة) | لتعديل أداة محددة |
| 3 | `css/tools-overrides.css` | تعديلات عامة **قسرية** تُحمَّل أخيراً وتفوز دائماً | لتغيير سريع يشمل الجميع |

**التوحيد تم بالكامل:** تم اعتماد النسخة الغالبة من كل قاعدة (340 اختلافاً قديماً بين الأدوات أزيلت لمصلحة التصميم الموحد). ملفات الأدوات الخاصة صارت ~4KB فقط.

**مثال عملي 1 — تصغير الصفحة كلها:** في `tools-overrides.css`:
```css
html { font-size: 13.5px !important; }  /* ← عدّل هذا الرقم لتكبير/تصغير كل شيء */
```
كل الأحجام والفراغات مبنية بوحدة rem، فتغيير هذا الرقم واحداً يصغّر/يكبّر الصفحة كاملة بشكل متناسق (الافتراضي 16px، والقيمة الحالية 13.5px ≈ تصغير 16%).

**مثال عملي 2 — حجم عنوان الأداة:** في نفس الملف، قسم `.hero-mini h2`.

## نظام اللغات

اللغات الثلاث تعمل من مكان واحد: **`js/i18n.js`**

- القاموس العربي `ar` والإنجليزي `en` موجودان، وأضفنا القاموس التركي `tr` كاملاً (104 مفتاحاً: واجهة، فئات، أسماء الأدوات الـ 32).
- عند اختيار اللغة من الإعدادات أو أزرار الدخول، تتغير اللغة والاتجاه (RTL للعربية / LTR للإنجليزية والتركية).

### منسدلة اللغة

- **شاشة الدخول**: منسدلة مع شعار الكرة الأرضية تحت العنوان (`#loginLangSelect`) — لتغيير اللغة قبل الدخول.
- **بعد الدخول**: من الإعدادات فقط (`languageSelect` + زر تطبيق) — لا منسدلة في الشريط العلوي أو صفحات الأدوات (حسب الطلب).
- عند تغيير اللغة تُعاد تسمية روابط الأدوات تلقائياً: العربية `toolN.html` — English `toolNen.html` — Türkçe `toolNtr.html`.

### تسمية ملفات الأدوات حسب اللغة (داخل مجلد tools/)

| اللغة | اسم الملف | مثال | CSS المشترك | ملف التعديلات |
|---|---|---|---|---|
| العربية | `toolN.html` | `tools/tool1.html` | `tools-common.css` | `tools-overrides.css` |
| English | `toolNen.html` | `tools/tool1en.html` | `tools-common-en.css` | `tools-overrides-en.css` |
| Türkçe | `toolNtr.html` | `tools/tool1tr.html` | `tools-common-tr.css` | `tools-overrides-tr.css` |

الصفحة الرئيسية توجّه تلقائياً إلى النسخة الصحيحة حسب اللغة المختارة.

**حالة النسخ:**
- العربية: **كاملة** (32/32) + `guide.html` + `survey.html`
- English: **كاملة** (32/32) + `guideen.html` + `surveyen.html`
- Türkçe: **كاملة** (32/32) + `guidetr.html` + `surveytr.html`

### ملاحظات مهمة على النسخة التركية

- الملفات التركية تُرفع **بدون لاحقة tr** (toolN.html بلغة تركية) — تُعالج بإعادة تسميتها `toolNtr.html` ثم نفس خطوات الإنجليزية.
- الأداتان 31 و32 تُرجمتا آلياً من النسخة الإنجليزية مع مراجعة كاملة للنصوص الباقية (واجهة + رسائل JS + تسميات Excel).

### معالجة دفعة لغة جديدة (الإنجليزية نموذجاً)

عند رفع ملفات `toolNen.html` تُنفَّذ نفس خطوات النسخة العربية:
1. التقسيم إلى `tools/` + `css/` + `js/` (سكربت داخلي)
2. `python3 scripts/unify_css.py en <مجلد-الملفات-المرفوعة>` — يوحّد CSS في `tools-common-en.css` ويعتمد النسخة الغالبة من كل قاعدة
3. نسخ `tools-overrides.css` إلى `tools-overrides-en.css` (نفس التصغيرات: الصفحة، العنوان، اللمس، التوسيط)
4. تحديث رقم الكاش في `sw.js`

### ملاحظات للنسخة التركية

- رابط بوابة الاشتراك (`portal.farouk-grup.com`) يستخدم حالياً رابط النسخة الإنجليزية للغة التركية — عدّله في `js/app.js` (داخل `applyLanguage`) عند توفر رابط تركي.
- `guidetr.html` و `surveytr.html` موجودان الآن — دليل المستخدم التركي يغطي الأدوات الـ32 كاملة.

## الاختبار المحلي (بدون سيرفر)

1. شغّل سيرفر محلي من داخل مجلد المشروع (مثلاً بأمر Python المدمج للسيرفر على منفذ 8000، أو إضافة Live Server في VS Code) ثم افتح `http://localhost:8000`
2. افتح `test-login.html` من متصفحك واضغط زر **دخول تجريبي** — تُنشأ جلسة صالحة حتى 2030 بدون كلمة مرور، ثم يُحوَّل تلقائياً للصفحة الرئيسية.
3. **احذف `test-login.html` قبل رفع المشروع على السيرفر.**

## إضافة أدوات جديدة أو النسخ الجديدة (الإنجليزية/التركية)

### الطريقة: سكربت التقسيم

عند رفع أداة جديدة (بأي لغة) شغّل:

```bash
python3 scripts/refactor_tool.py <مسار الملف> <الاسم>
# مثال:
python3 scripts/refactor_tool.py ~/Downloads/tool16.html tool16
python3 scripts/refactor_tool.py ~/Downloads/tool16tr.html tool16tr
```

السكربت سيقوم تلقائياً بـ:
1. فصل CSS إلى `css/tools/<الاسم>.css`
2. فصل JS إلى `js/tools/<الاسم>.js`
3. ترك HTML نظيف في `tools/<الاسم>.html`
4. تصحيح مسارات `auth-check.js` و`index.html` تلقائياً

### ثم: تسجيل الأداة في الصفحة الرئيسية

أضف سطر الأداة في `js/app.js` داخل `toolCategories` (القسم الموجود في الأسفل)، مثال:

```js
{ nameKey: "tool_feasibility", icon: "fa-chart-pie", file: "tool1.html" },
```

وإذا كانت أداة جديدة (ليس لها مفتاح) أضف اسمها بالثلاث لغات في `js/i18n.js`:

```js
// ar:
"tool_new": "اسم الأداة بالعربية",
// en:
"tool_new": "Tool Name in English",
// tr:
"tool_new": "Türkçe Araç Adı",
```

## الحماية (النسخة المحصّنة)

تمت ترقية نظام الحماية بالكامل — ملفات التطبيق في مجلد `security/`:

| الملف | وظيفته |
|---|---|
| `security/apps-script-secured.js` | الجوجل سكربت المحصّن (يُلصق في Apps Script مكان القديم) |
| `security/worker-secured.js` | الوسيط المحصّن في Cloudflare (فحص النطاقات + حجب دوال الإدارة) |
| `security/تعليمات-التطبيق.md` | دليل التطبيق خطوة بخطوة (30-40 دقيقة، مرة واحدة) |

أبرز التحسينات: توكن موقّع HMAC (لا مفتاح في المتصفح)، كلمات مرور مشفّرة SHA-256، دوال إدارة محمية بمفتاح، حد لمحاولات الدخول، فحص التجميد في validate، وحد للسبام في التسجيلات.

**ملاحظة**: `js/auth-check.js` أصبح الإصدار 6.0 — توكنات النظام القديم غير صالحة وسيُعاد تسجيل دخول المستخدمين مرة واحدة.
