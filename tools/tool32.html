📈 المعدل السنوي المركب (CAGR)

الاسمي والحقيقي — مع مراعاة أثر التضخم على القوة الشرائية للاستثمار

CAGR

حاسبة CAGR الاسمي والحقيقي

📊 المدخلات الأساسية
💸 التضخم (اختياري — لحساب المعدل الحقيقي)
اتركه = 0 لتعطيل حساب المعدل الحقيقي
CAGR الاسمي = (End / Start)1/n − 1

CAGR الحقيقي = [(1 + CAGR) / (1 + التضخم)] − 1
⚖️ مقارنة استثمارين (اختياري)
🎯 مؤشرات الأداء الرئيسية
📋 تفصيل الحسابات
📋 جدول النمو المركب (سنة بسنة)
📈 منحنى النمو (الاسمي / الحقيقي / البسيط)
⚖️ مقارنة الاستثمارين
ملاحظة: CAGR الاسمي يقيس النمو بالأسعار الجارية، بينما CAGR الحقيقي يقيس النمو بعد استبعاد أثر التضخم (أي نمو القوة الشرائية الفعلية). إذا كان CAGR الحقيقي سالباً، فمعنى ذلك أن استثمارك يخسر قوة شرائية رغم نموه اسمياً.
